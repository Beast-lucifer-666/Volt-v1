# Volt-v1 - Smart Home Energy Monitoring

Volt-v1 is a modern Android application designed for real-time monitoring and control of home electrical appliances. It provides users with deep insights into their energy consumption, voltage fluctuations, and allows for remote device management.

## 🚀 Features

- **Real-time Monitoring**: Track voltage, current, and power consumption live.
- **Smart Dashboard**: A beautiful interface showing your home's energy health at a glance.
- **Remote Relay Control**: Toggle appliances like AC units, lights, and fridges from anywhere.
- **Detailed Analytics**: Visualize energy usage patterns over days, weeks, and months.
- **Safety Alerts**: Monitoring service for critical voltage fluctuations and electrical safety.
- **Environmental Impact**: Track your CO2 savings and bill estimates.
- **Firebase Integration**: Secure authentication and real-time data synchronization.

## 🏗️ Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/Volt-v1.git
    ```
2.  **Open in Android Studio**:
    Import the project as a Gradle project.
3.  **Firebase Setup**:
    -   Create a project on the [Firebase Console](https://console.firebase.google.com/).
    -   Add an Android app with the package name `com.example.myapplication`.
    -   Download `google-services.json` and place it in the `app/` directory.
4.  **Build and Run**:
    Click the "Run" button in Android Studio.
